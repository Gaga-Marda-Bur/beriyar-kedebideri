2. فئات البيانات التي يتم جمعها

  • الاستخدام كضيف (دون حساب): يمكنك استخدام التطبيق وتصفح الدروس دون إنشاء حساب؛ تُحفظ لغة الواجهة وتقدمك المحلي والملفات الصوتية المخبأة على جهازك فقط.
  • بيانات الحساب الاختياري: عند التسجيل أو تسجيل الدخول، تتم معالجة اسم المستخدم (username)، والبريد الإلكتروني (اختياري تماماً)، وكلمة المرور (محفوظة بصيغة مشفّرة غير قابلة للعكس).

  • الملاحظات التقنية (اختيارية): نص الملاحظة، ولقطة شاشة أو مقطع صوتي إن أرفقتها طوعاً.

2. Categories of Data Collected

  • Guest use (no account): You can use the app and browse lessons without creating an account; interface language, local progress, and cached audio remain on your device only.
  • Optional account data: If you register or sign in, we process your username, optional email, and password (stored in hashed form).
  • Session and learning progress: User ID, unit/lesson progress, review state, sync identifier, and authentication session tokens (sessionid / csrf).
  • Optional technical feedback: Message text, and any screenshot or audio file you voluntarily attach.
  • Data not collected: The app does not collect date of birth, does not request camera, microphone, location, or contacts permissions, and includes no advertising, payments, or third-party ad tracking SDKs.
{% else %}

2. Catégories de données collectées

  • Utilisation en mode invité (sans compte) : Vous pouvez utiliser l’application et suivre les leçons sans créer de compte ; la langue d’interface, la progression locale et l’audio mis en cache restent uniquement sur votre appareil.
  • Compte apprenant (optionnel) : En cas d’inscription ou de connexion, nous traitons votre identifiant (username), votre adresse e-mail (strictement optionnelle) et votre mot de passe (conservé sous forme hachée).
  • Session et progression pédagogique : Identifiant utilisateur, avancement par unité/étape, état de révision, identifiant de synchronisation et jetons de session (sessionid / csrf).
  • Signalements techniques (optionnels) : Texte du signalement et, si vous les joignez volontairement, capture d’écran ou enregistrement audio.
  • Données non collectées : L’application ne collecte pas de date de naissance, ne demande ni caméra, ni microphone, ni localisation, ni contacts, et n’intègre ni publicité, ni paiement, ni SDK de suivi publicitaire.
{% endif %}

6. Your Rights and Account Deletion Procedure

You may request access to, correction of, or deletion of your data by writing to privacy@beriyarkedebideri.com, or submit a password-verified deletion request directly from the Android app settings or via /account-deletion/.

  • Manual processing (not instantaneous): Submitting a request records a reference code (DEL-...) without immediate automatic deletion; an administrator verifies and executes the deletion manually.
  • Scope of erasure and anonymization: Atomic administrative execution deletes the user account, associated learning progress, sync credentials, and active sessions; anonymizes technical feedback (clearing both user link and device identifier); dissociates the user link from public No Ena publications; and scrubs the username and free-text note from the deletion request record while keeping a minimal non-identifying audit trace (reference code, status, timestamps).
  • Limits: Database backups and external infrastructure logs retain snapshots until their scheduled rotation expires. [TO BE CONFIRMED BY OWNER — official request processing timeframe]
{% else %}

6. Vos droits et procédure de suppression de compte

Vous pouvez demander l’accès, la rectification ou la suppression de vos données en écrivant à privacy@beriyarkedebideri.com, ou déposer une demande de suppression confirmée par mot de passe depuis les réglages de l’application Android ou la page /account-deletion/.

  • Traitement administratif manuel (non instantané) : L’envoi d’une demande enregistre un code de référence (DEL-...) sans suppression automatique immédiate ; l’administrateur vérifie et exécute l’effacement manuellement.
  • Périmètre d’effacement et d’anonymisation : L’exécution administrative atomique supprime le compte utilisateur, les progressions pédagogiques associées, les jetons de synchronisation et les sessions actives ; anonymise les signalements techniques (suppression du lien utilisateur et de l’identifiant d’appareil) ; dissocie le lien utilisateur des publications publiques No Ena ; et purge l’identifiant ainsi que la note libre de la demande de suppression en ne conservant qu’une trace minimale non identifiante (référence, statut, dates).
  • Limites : Les sauvegardes techniques de base de données et les journaux des prestataires d’infrastructure subsistent jusqu’à l’expiration de leur cycle de rotation. [À CONFIRMER PAR LE RESPONSABLE — délai officiel de traitement des demandes]
